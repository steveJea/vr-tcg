1. 처리 주체와 적용 범위

엔터인코드(ENT.INCODE)는 VR: Abyss Gate 운영에 필요한 개인정보의 처리 목적·항목·보유 기준·권리행사 방법을 이 초안으로 설명합니다. 법적 사업자명은 엔터인코드(ENT.INCODE), 대표자는 장윤석, 사업자등록번호는 738-44-01302이며 사업장 주소는 [사업장 주소 입력 필요]입니다. 자세한 사업자 정보는 이용약관 제2조를 확인하세요.

게임은 Supabase 인증·데이터베이스와 Cloudflare 정적 호스팅을 사용합니다. 기존 tcg.mbbs.kr의 GitHub Pages 경로가 병행될 수 있습니다. 운영과 staging은 별도 Supabase 프로젝트·DB를 사용하며 테스트에서 입력한 정보도 개인정보 보호 대상입니다.

이메일이 없어도 지원되는 공급자 설정에서 게임 가입이 가능합니다. 닉네임이나 이메일이 같다는 이유만으로 서로 다른 계정의 진행도를 임의로 합치지 않습니다. 공개 입력란에 실명·연락처 등 불필요한 개인정보를 넣지 마세요.

현금 결제는 현재 준비 중입니다. 향후 유료 판매 시 주문번호·상품·금액·결제/취소 시각·거래 확인 값 등 필요한 항목과 결제업체를 추가 고지합니다. 현재 게임이 카드번호·주민등록번호를 직접 입력받는 결제 화면은 없습니다. [결제사업자·상품별 판매/환불정책 확정 필요].

3. 처리 근거와 선택

서비스 계약 체결·이행에 필요한 회원 식별과 게임 저장, 관계 법령에 따른 의무 이행, 적법하게 받은 동의 등 해당되는 근거에 따라 필요한 범위의 정보를 처리하는 것이 원칙입니다. 목적별 적용 근거·선택 동의 사항은 실제 운영에 맞게 확정해야 합니다. [목적별 처리근거·선택 동의사항 확정 필요].

소셜 로그인 공급자가 고지하는 제공 범위를 확인하고 이용할 공급자를 선택할 수 있습니다. 필요한 정보의 제공을 거부하면 계정 기능 이용이 제한될 수 있으나 이메일 미제공만으로 무조건 가입을 제한하도록 설계한 것은 아닙니다. 게스트 이용 중에도 접속·통계 정보는 처리될 수 있습니다. 이 문서의 공개나 링크 열람은 별도 동의를 대신하지 않습니다.

4. 보유·이용 기간과 파기

기본 기준은 회원의 서비스 이용 동안 목적에 필요한 범위만 보유하고, 탈퇴·목적 달성·보유기간 만료 시 법정 보존 대상 외 정보를 지체 없이 파기하는 것입니다. 다만 현재 코드에 전체 계정 자동 삭제나 일괄 보유기간 만료 처리 기능이 구현되었다고 볼 수 없습니다. 아래 일정·실제 파기 절차를 확정하고 운영과 일치시켜야 합니다.

  • 계정·게임 정보: 회원 유지 기간을 기준으로 하되 [회원 탈퇴·삭제 처리절차와 처리기한 확정 필요].
  • 접속·보안·부정 이용·문의 기록: 목적별 최소 기간과 근거를 정하여 [기록별 보유기간·파기 일정 확정 필요].
  • 백업·복구본: 실제 Supabase 플랜과 백업 설정에 따른 보존 기간·삭제 반영 시점을 확인하여 [백업 보유·삭제 반영기간 확정 필요]. 삭제 요청 직후 모든 백업이 즉시 지워진다고 보장하지 않습니다.
  • 브라우저 정보: 이용자가 삭제하거나 각 항목의 필요가 끝날 때까지 남을 수 있습니다. 계정 연결 문맥은 최대 20분 이내 유효한 일회성 정보이며 페이지 종료 등으로 sessionStorage가 삭제될 수 있습니다. 로그아웃이 모든 설정·게스트 기록·통계 쿠키를 지우는 것은 아닙니다.

7. 쿠키·브라우저 저장소·Google Analytics

게임 화면에는 Google Analytics 태그가 있어 페이지 조회·기기/브라우저·쿠키 식별자 등 통계 정보가 전송될 수 있습니다. 로그인 세션·설정·게임 캐시는 쿠키와 다른 localStorage/sessionStorage에도 보관될 수 있습니다. 브라우저에서 쿠키와 사이트 데이터를 차단·삭제할 수 있으며 로그인 유지나 게스트 기록 등 일부 기능이 제한될 수 있습니다.

게임 리소스(그림·음성·영상 등)를 기기에 저장해 더 빠르게 불러올 수 있어요. 서비스 워커와 브라우저 저장소(Cache Storage)를 쓰며 개인정보는 담기지 않아요. 게임설정 › 설정 › 캐시 삭제나 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있어요.

현재 게임 안에 별도의 분석 수집 동의 배너·거부 스위치는 구현되어 있지 않습니다. Google Analytics는 공식 차단 도구 등으로 거부할 수 있으나 브라우저 쿠키 차단만으로 모든 외부 요청이 차단된다고 보장하지 않습니다. [GA4 보유기간·법적근거·동의/거부 방식 확정 필요].

이 약관·개인정보처리방침 페이지 자체에는 분석·인증 스크립트, 외부 웹 폰트, 입력 폼을 넣지 않았습니다. 다만 페이지 전달에 필요한 호스팅/CDN의 접속 처리는 발생합니다.
