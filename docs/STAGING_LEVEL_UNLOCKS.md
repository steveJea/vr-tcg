## 짧은 소개·체험·보상

- 잠긴 버튼은 `🔒 LvN`만 표시합니다. 소개는 홈 로비에서 한 장씩, 전투·대화·영상·다른 팝업 중에는 나오지 않습니다.
- 시트의 소개/보상 내용을 바탕으로 짧은 소개를 표시합니다. Lv8/17/18/20/25/40에는 시트에 없던 추가 재화 보상을 만들지 않았습니다.
- 탑: 일반 전투 **한 판 결과 제출**이면 체험 완료(패배도 가능). 소탕은 요구하지 않습니다. 이미 한 판 진행한 계정은 반복 체험하지 않습니다.
- 훈련소: 가장 낮은 레벨 인재에 `추천` 표시. 다른 인재도 직접 선택 가능. 한 번 배정한 사실은 빼기 후에도 유지됩니다.
- 탑/훈련소는 체험을 나중에 할 수 있지만 완료 전에는 해당 체험 보상만 보류합니다. 인재가 없거나 훈련 가능한 인재가 전혀 없으면 안내만으로 완료할 수 있습니다. 가입·구매·재료 지출을 강요하지 않습니다.
- 다른 소개는 확인 시 서버에서 1회 지급합니다. 조직 미가입·강화 재료 부족 때문에 안내/보상이 막히지 않습니다.
- **CH0 소환권 10장은 기존 챕터 클리어 보상에 이미 포함되어 있으므로 중복 지급하지 않습니다.** 기존 강제 10회 소환/하지은 보장 경로를 유지합니다.
- 희귀 장비상자/증표조각 선택상자는 기존 우편 형식으로 지급(14일 수령 기간). 증표 선택지는 기존 토벌 선택상자와 같습니다.
- 재접속·중복 요청·SQL 재실행에도 보상 중복 없음. 클라이언트 재화/EXP 입력을 신뢰하지 않습니다.

## 연마소·도장: 충돌 발견 → 이번 변경에서 보류

시트의 Lv20을 그대로 건물 레벨 제한에 대입하면 다른 효과까지 바뀝니다.

- 연마소: 훈련소 Lv5 필요 → 현 계정 Lv35 (`5 × 건물레벨 + 10`).
- 도장: 훈련소 Lv8 필요 → 현 계정 Lv50.
- 건물 Lv2~8을 계정 Lv20까지 당기면 훈련 EXP 배율도 일찍 **1.35배**가 됩니다(현재 Lv1=1.00배). 단순 메뉴 해금 이상의 밸런스 변화입니다.
- 건물 Lv5까지 총 150,000 골드, Lv8까지 추가 1,000 심연석. 도장 첫 칸은 별도 1,500 심연석, 둘째 칸 1,000. 건물 제한만 낮춰도 자동 무료 개방은 아닙니다.
- 연마소의 골드/장비 가루, 도장의 골드/혼, 작업 시간·강화 상한·개별 스킬 습득 레벨 조건은 별도입니다. 조직/시즌 의존은 없습니다.

**실제 충돌이면 옵션을 보고하라는 조건에 따라 건물 제한·시설 소개/5000골드 보상은 아직 변경하지 않았습니다.**

선택지:
1. **추천:** 시설만 계정 Lv20에 독립 해금. 훈련소 건물 레벨/EXP 배율은 그대로, 기존 재료/도장 칸 비용 유지.
2. 건물 Lv2~8의 계정 제한도 Lv20 이하로 낮추고, 더 빨리 받는 훈련 배율/기존 심연석 비용까지 함께 승인.

## 확인할 것

- Lv1 계정: 시작 메뉴 열림, PvP/조직/파견 등은 자물쇠+레벨. CH0→CH1→다음 챕터 순서.
- 각 경계의 직전/해당 레벨: 버튼과 직접 RPC 최소 레벨 일치. PvP 6개 리그/모드 조합.
- 전투 중 레벨업 후 홈 복귀: 그때 소개, 영상 종료 전에는 안 나옴.
- 소개 확인→새로고침→SQL 재실행: 같은 보상 추가 없음. 계정 EXP도 증가하지 않음.
- 토벌 Lv11/조직전 Lv18: 조직/시즌/참가 자격은 기존 조건 그대로. 기존 phase4 seed/refill도 유지.
- 탑 한 판(패배 포함) 후 체험 보상, 소탕 불필요. 훈련소에서 추천 외 다른 인재 배정 가능.
