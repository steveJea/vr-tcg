- 지금 숫자는 처음 값이에요. 실제로 하루에 얼마나 풀리는지 보고 조정해요.

## 하단·상단 메뉴로 이동할 때 팝업 남는 문제 (fix/nav-close-popups)
- 증상: 내 카드에서 카드 상세(스탯·장비·스킬) 팝업을 연 채 하단 메뉴를 누르면 화면은 바뀌는데 팝업이 위에 남음.
- 고침: 하단 메뉴(js/gnb.js) 어느 칸을 눌러도 **먼저 떠 있는 작은 창을 모두 닫고** 이동. 닫는 순서·대상은 뒤로가기와 같은 목록(pages.js `closeTopOverlay`: 확인창(=아니오)·확대·카드 상세·갤러리 상세·스토리 팝업·드링크 확인·도움말·장비/조직/거래/PvP 작은 창) + 심연석 창. 새 `VRPages.closeOverlays()` (페이지 안 단계 뒤로는 안 건드림).
- 상단 바 ←/⌂ (js/topnav.js): 작은 창이 떠 있으면 그것부터 닫고, 한 번 더 누르면 원래 뒤로.
- 메뉴를 가리는 방식 대신 이 방식을 고른 이유: 팝업 중에도 하단 메뉴로 바로 이동할 수 있고, 어떤 경로로 이동해도 팝업이 남지 않음.
- 테스트: Chromium·Firefox 390, 카드 상세 열고 홈·소환·탑·조직·PvP·마이 각각 → 팝업 사라짐, 브라우저 뒤로 = 팝업만 닫힘, 상단 ← 두 번 = 팝업 닫힘 → 스토리 허브. 화면 `/workspace/navfix/*`.
