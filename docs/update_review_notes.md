## 파견 (2026-11-01 첫 버전)

### 1. 파견 전용 새 아이템 — 보류
- 예: "배척지 유물" 같은 파견에서만 나오는 아이템.
- 지금은 있는 재화만 줘요: 골드 · 순수한 피 · 이상한 조각 · 각성자의 혼 · 심연석 · 소환권 · 드링크.
- 처음 계획에 있던 인장 조각 · 장비 상자도 이번엔 빼고, 각성자의 혼 · 심연석으로 바꿨어요. 넣으려면 우편(player_mail)으로 보내는 방식이 필요해요.

### 2. MR · LR 파견 단계 — 보류
- 지금은 MR · LR 카드는 파견을 보낼 수 없고, MR 이상이 필요한 파견지도 없어요.
- 가장 높은 곳은 배척지 009 (UR 필요).
- 나중에 배척지 010 · 안전지대 SSS급 같은 단계를 만들고, MR · LR 카드를 보낼 수 있게 할지 정해야 해요.

### 3. 보상 숫자 조정 — 경제 확인 후
- 지금 숫자는 처음 값이에요. 실제로 하루에 얼마나 풀리는지 보고 조정해요.
- 특히 볼 것: 심연석(배척지 007~009, 안전지대 SS급), 소환권(안전지대 S · SS급), 골드.
- 숫자는 서버 표 dispatch_zones 의 rw 칸(1시간 기본 보상)만 고치면 바로 바뀌어요.
- 같이 볼 것: 하루 12번 제한, 새로고침 비용(무료 3번 → 심연석 20/30/40/50), 시간 배수(1/4/8/12시간 = ×1/×3.5/×6/×8.5).

### 4. 기타 메모
- 새 카드는 신규 카드 SQL(pvp_card_meta · story_card_pool)을 돌리면 파견 표에 등급이 자동으로 들어가요. 속성·클래스 보너스만 dispatch.sql 을 다시 돌릴 때 채워져요.
- 각성 카드는 따로 된 카드예요: [각성] 윤진아(10291) = UR → 파견 가능, [각성] 임유리(10326) = MR → 지금은 파견 불가.
- 등급은 카드 원래 등급 기준이에요 (각성 등으로 바뀐 등급은 아직 반영 안 함).

## 페이지 시스템 (팝업 → 페이지 전환) — ✅ 완료 (2026-11-02, #396~#404 + 정리)
- 뼈대: js/pages.js + css/pages.css. 주소 `#/이름`, 브라우저 기록 기반 뒤로가기 (폰 뒤로 = 화면 ← 버튼)
- 로비에서 뒤로: 열린 작은 창부터 닫고, 스토리 화면이면 그 화면의 '←', 아무것도 없으면 '게임을 나갈까요?'
- 뒤로가기 순서: ① 맨 위 작은 창(Y/N 확인 = 아니오, 카드 상세, 갤러리 확대/상세, 장비·조직·PvP 작은 창) ② 페이지 안 한 단계(탑 결과→탑→탑 목록, PvP 보스리그 덱 단계) ③ 페이지 닫기
- 전투·영상·스토리 대사 중엔 뒤로가기 무시. 전투 화면이 보이면 페이지는 숨고 끝나면 다시 보임
- 페이지 목록
  - 1~3단계: 도움말, 친구, 랭킹, 일일 미션, 음료, 마이페이지, 도감, 심연석 상점
  - 4단계: 파견, 장비 가방, 우편함, PvP 상점 / 5단계: 탑 / 6단계: 토벌, 구역 전쟁
  - 7단계: 조직 + 하위(대여·대여 등록·상점·가입 신청·설정·기록·집결·의뢰). 조직에서 연 토벌/전쟁은 조직 위로 쌓임
  - 8단계: PvP + 하위(덱 편집·랭킹·시즌 보상) / 9단계: 스토리 출전 고르기·스탯 분배·합성 미리보기·일괄 분해·소탕
- 만드는 법: 예전 팝업을 그대로 페이지에 담기 `VRPages.host(이름, 제목, 팝업요소, leave?, show?, onBack?)` → 팝업.remove() = 뒤로. 새 화면은 `VRPages.register(이름, { title, render, leave, onBack })` + `VRPages.open(이름)`
- 확인창: 브라우저 confirm() 대신 `await VRAsk('글')` (게임 Y/N, 폰 뒤로 = 아니오). 조직·파견·장비·전쟁·친구·닉네임·소환권 구매 바꿈 (관리자 화면은 그대로)
- 예전 팝업 코드는 일부러 남겨 둠: 페이지가 실패하면(오류·VRPages 없음) 예전 팝업으로 열림. 같은 코드가 페이지 안 내용을 그리므로 지우면 페이지도 안 그려짐
