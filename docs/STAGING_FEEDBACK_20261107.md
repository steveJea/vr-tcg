# 2026-11-07 테스트 서버 피드백 수정

기준: `origin/sec/phase1-rewards-20261107` (`e2964d4`). 실 DB 접근·적용 없음.

1. **스토리 이벤트 그림**: `object-fit: cover`와 Ken Burns 확대가 원본을 잘랐고, 데스크톱 대사 높이는 모바일과 달리 실제 가용 높이를 따르지 않았음. `contain`으로 원본 전체 표시, 확대 제거, 모든 해상도에 `dvh` 높이 적용. 대사 상자·뷰포트 변경 시 미디어 높이를 다시 계산하고 장면을 떠날 때 리스너 정리.
2. **유리의 턴 종료 안내**: 자동 턴 종료와 가이드가 서로 독립적으로 작동하고, 가이드가 지시한 턴 종료에도 일반 미행동 카드 확인창이 열려 가이드 입력 차단과 충돌했음. 가이드 중 자동 종료 중지, 턴 종료를 직접 안내하는 단계에서만 확인창 생략. 평소 확인창/설정은 유지.
3. **전투 결과 하단 메뉴**: 전투 DOM은 이미 숨겼지만 결과 화면을 GNB의 busy 조건에서 빠뜨렸음. 승리·패배·결과 저장 실패 화면을 명시적으로 표시해 메뉴를 숨김. 다음 화면으로 나가면 복구. 화면 전환 시 내비게이션을 즉시 다시 그려 대사 높이 측정과의 시차도 제거.
4. **작은 기술 연출**: 보안 1단계 회귀 아님. 기존 `main`과 동일한 `css/battle-fx3.css`의 40vh(가로)/32vh(세로) 축소 덮어쓰기가 원인. 이를 제거해 기본 70vh/62vh 크기로 복원하고 모바일 주소창을 반영하는 `dvh` 보완. 연출 시간은 변경하지 않음.
5. **보상 받기와 심연석 부족**: 캡처에서 누른 것은 누적 보상이 아니라 **심연석 30개로 4시간분을 즉시 받는 빠른 보상**. 기존 서버 계약이고 보안 1단계는 이 RPC/요금을 바꾸지 않음. 무료 누적 받기와 심연석 사용 버튼을 분리 표기하고, 빠른 보상은 사용량 확인 후에만 호출. 중복 클릭 방지. 오프라인 PGlite에서 심연석 0개로 무료 누적 받기 성공, 빠른 보상은 잔액 부족 시 전체 롤백, 잔액 보유 시 30개 차감·하루 2회 제한 확인.
